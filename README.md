# CURVE Protocol

Public source for the CURVE finite-reserve absorption protocol deployed on Solana mainnet.

- Program ID: `38P3f9cKZhKb2rPDrzb3DVAV4NRhZ1qGUGJetYiPpee4`
- Framework: Anchor 0.32.1
- Network: Solana mainnet-beta

This repository exists for reproducible-build verification and independent review. A verified build proves that this source compiles to the deployed bytecode; it does not constitute a security audit.
